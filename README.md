# GravShot

GravShot is an experimental, AI-assisted JavaScript game prototype inspired by
WarHeads SE, an old PC artillery game I spent a lot of time playing in the 2000s.

I built it to recreate some of the fun of turn-based space artillery while
experimenting with real-time browser multiplayer, Socket.IO, and simple
gravity-based mechanics.

It is still rough around the edges and needs refinement, but it captures the core
idea I wanted to test: players taking shots around planetary gravity in a shared
browser game.

## Tech Stack

- Node.js
- Express
- Socket.IO
- Browser-based JavaScript, HTML, and CSS

## Run Locally

```bash
npm install
npm start
```

Then open the local server URL shown in the terminal.
